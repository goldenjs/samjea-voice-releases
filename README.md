# SAMJEA Voice

SAMJEA Voice is a free voice-first Android messaging app designed for simple everyday conversations.

## Features

- Voice messages
- Text messages
- Image sharing
- Group conversations
- Arabic, English, and French

## Download

Download the latest official APK from the [Releases page](https://github.com/goldenjs/samjea-voice-releases/releases/latest).

Current release: **v0.12.5**

Official website: https://samjea.sbs

## Installation

Download the APK on your Android device, open it, and follow Android's installation prompts. You may need to allow installation from your browser or file manager.

## Authenticity

This repository contains official SAMJEA Voice APK releases published by the SAMJEA team. The application source code is maintained separately and is not included in this distribution repository.
